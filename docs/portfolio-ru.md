# Портфолио RainCherb — AI-интеграция и разработка с ИИ

**Специализация:** практическое внедрение искусственного интеллекта, автоматизация задач, AI-assisted development, LLM-инструменты и AI-агенты.

[Профиль GitHub](https://github.com/RainCherb) · [Context Diamond](https://github.com/RainCherb/context-diamond) · [InsightLoop](https://github.com/RainCherb/insightloop) · [BidWise AI](https://github.com/RainCherb/bidwise-ai) · [NeuroMap](https://github.com/RainCherb/NeuroMap)

## Что умею и предлагаю

- **Подбор ИИ-инструментов для бизнеса.** Сравнение моделей, их качества, стоимости, ограничений, доступности в России и применимости для разных задач.
- **Автоматизация рабочих процессов.** Анализ ручных операций и поиск сценариев, где можно использовать LLM, агентов и программные инструменты.
- **AI-assisted разработка.** Создание прототипов и приложений с помощью AI coding agents: Codex, Claude Code, OpenCode, Kiro и других инструментов.
- **MCP и агентные сценарии.** Передача контекста между агентами, интеграция инструментов и разработка вспомогательных решений.
- **Обучение и сопровождение.** Объяснение сотрудникам практических сценариев применения ИИ и безопасных подходов к использованию моделей.

> Ниже — самостоятельные проекты, а не вымышленные места работы или коммерческие внедрения. В проектах использовалась разработка с помощью ИИ; сложность, технические детали и ограниченные возможности описаны по опубликованным исходникам.

## Ключевые проекты

### 1. [Context Diamond — передача контекста между AI-агентами](https://github.com/RainCherb/context-diamond)

CLI-инструмент для сжатия больших текстовых контекстов до проверяемых «капсул», которые можно передавать между LLM, coding agents и этапами работы. В проекте есть сравнение результатов, аудит отброшенной информации, шаблоны и интеграция с OpenCode через MCP.

**Практическая задача:** сократить повторяющуюся передачу контекста и сохранить ограничения, решения и текущее состояние при смене агента. **Стек:** Python, LLM tooling, MCP.

### 2. [InsightLoop — анализ обратной связи клиентов с помощью ИИ](https://github.com/RainCherb/insightloop)

Self-hosted система, которая помогает анализировать отзывы, обращения и текстовые ответы: тональность, темы, срочность, возможные действия. Есть панель аналитики, загрузка CSV, REST API, отчёты и варианты подключения LLM-провайдеров (OpenAI, Anthropic, Ollama) либо демонстрационного режима.

**Практическая задача:** быстрее разбирать поток сообщений клиентов и находить повторяющиеся проблемы. **Стек:** Python, FastAPI, REST API, аналитика, LLM.

### 3. [BidWise AI — предварительная оценка тендеров и запросов](https://github.com/RainCherb/bidwise-ai)

Приложение для структурированной первичной оценки тендера/RFP: риски, критерии, бюджет, сроки, вопросы к заказчику и черновик стратегии. Первичная оценка основана на **прозрачных правилах в браузере**, без отправки введённых данных на внешний сервер. Для углублённого разбора формируется промпт для выбранной пользователем LLM.

**Практическая задача:** стандартизировать предварительную оценку заявок и не тратить время на неподходящие предложения. **Стек:** React, TypeScript, аналитика требований, AI-ready workflow.

### 4. [NeuroMap — карта проекта для coding agents](https://github.com/RainCherb/NeuroMap)

CLI-инструмент, который формирует структурированное описание репозитория: языки, файлы, точки входа и карту для передачи AI-агенту. Поддерживает Markdown, JSON, XML и генерацию `CLAUDE.md`.

**Практическая задача:** помочь coding agent быстрее разобраться в незнакомой кодовой базе. **Стек:** Python, CLI, инструменты контекстной подготовки.

## Подход к работе

**Результат важнее модного названия модели.** Выбираю инструменты в зависимости от задачи, бюджета, требований к данным и ограничений развёртывания. Для конфиденциальной информации и корпоративных данных требуется отдельная оценка безопасности и правил компании.

Базовые знания программирования сочетаю с практикой разработки с ИИ-агентами. Не представляю себя как разработчика с многолетним коммерческим стажем: технические решения оцениваю и дорабатываю по результату, с проверкой и тестированием.
